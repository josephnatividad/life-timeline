# ADR-0008: One-Time Pro as Primary Monetization

-   Status: Accepted
-   Date: 2026-08-09

## Decision

The core monetization strategy is a useful permanent Free tier plus a
one-time Pro purchase.

Free retains access to core timeline data and receives a generous taste
of Pro intelligence.

Subscriptions are reserved only for future services that create real
recurring developer costs.

## Sustainability

Future revenue may include new Pro customers, major-version upgrades,
meaningful expansions, local AI packs, Life Books/physical products, and
optional hosted services.
