# ADR-0003: Entity/Event/Evidence/Relationship Model

-   Status: Accepted
-   Date: 2026-08-09

## Decision

Represent personal history using Entities, Events, Evidence and
Relationships rather than a single generic timeline-entry table.

Support field provenance, confirmation state and temporal precision.

## Rationale

This enables reliable retrieval, longitudinal histories, duplicate
resolution and evidence-backed answers.
