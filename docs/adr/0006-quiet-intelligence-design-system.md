# ADR-0006: Quiet Intelligence Design Direction

-   Status: Accepted
-   Date: 2026-08-09

## Decision

Use the "Quiet Intelligence" design language: warm/neutral surfaces,
restrained indigo intelligence accent, strong typography, temporal
visual structure, subtle motion and expressive Stories.

Avoid neon AI aesthetics, excessive glassmorphism, decorative animation
and generic card feeds.

## Icons

Use Hugeicons Free as the primary universal icon set, subject to license
verification, wrapped behind `AppIcons`. Create a small custom signature
icon set.
